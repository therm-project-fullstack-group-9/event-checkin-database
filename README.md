# Term Project - Database

## Setup
  ### 1. Clone Repository
  - git clone <URL's Repository>
  ### 2. Install Dependencies
  - pnpm install
  ### 3. Setting Environment Variables
  - create .env 
  ### 4. Start the database
  - docker compose up -d

## Usage
  - pnpm run db:push
  - pnpm run db:generate
  - pnpm run db:migrate  
  - pnpm run db:prototype
